# Indienststellingsverslag

Invulbare webapp voor een indienststellingsverslag in Chevron-stijl.

## Bestanden
- `index.html`: structuur van het rapport en de interface
- `styles.css`: opmaak van het rapport en de invulvelden
- `app.js`: veldlogica, synchronisatie en print/export
- `netlify.toml`: eenvoudige static deploy-config
- `start-preview.bat`: lokale preview opstarten op Windows
